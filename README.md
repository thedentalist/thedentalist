# thedentalist
The Dentalist Website

## Online appointment requests

The Hungarian and English contact pages submit appointment requests to [Formspree](https://formspree.io/f/xqpppgjk). Requests are not confirmed automatically; the clinic reviews each one and confirms it with the patient.

The Formspree form receives the requested service, date and time, name, phone number, email address, request status, and language as JSON. Manage the form's notification recipient and spam protection in the Formspree dashboard.
